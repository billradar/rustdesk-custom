# 已抛弃的历史 Patchsets

v1 与 v2 已停止维护，不再接受功能、修复、适配或 revision 更新。此目录只保存原始历史证据，内容不得修改。

按用户确认的新要求，所有新 CI、Nightly、Stable 构建均禁止使用 v1/v2，包括 RustDesk 1.5.0、1.5.1 和原先使用 v1 的旧版本。选择器及补丁应用完整性入口会明确报 retired 错误，不回退到 v3。当前只维护 v3；其他尚未适配版本继续按既有 latest-maintained 兼容测试政策处理。

这取代此前要求保留 1.5.1 重建能力的约束；历史 Tag、Release、签名和已发布产物不变，不做覆盖或删除。旧构建所用补丁可从原历史提交核验。本目录不是构建输入，不是第二个补丁选择来源。
