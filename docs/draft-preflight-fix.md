# Draft visibility and early deduplication

Scheduled Stable run [36932216497](https://github.com/billradar/rustdesk-custom/actions/runs/36932216497) was triggered by `schedule`. Compatibility, Prepared Source, both Windows builds, pair validation and aggregate passed. The final draft job failed with `Existing revision draft`. The earlier read-only discovery token could not see the existing unpublished draft, while the final release token could. No existing release was changed. Overall scheduled run: FAIL.

Stable discovery now resolves the official tag/SHA once using a read-only job. An independent `draft-preflight` release-lifecycle job downloads the same-run discovery artifact and checks the existing revision before compatibility or expensive builds. GitHub requires Contents write access to view unpublished drafts, so only this release preflight and the final Draft job have that permission. The preflight executes GET requests only, has no client configuration secrets and never publishes or modifies releases. CI, Nightly, compatibility and build jobs retain read permissions; no PAT is introduced.

Complete matching Draft/Release: skip builds and creation. Explicit force rebuild: artifacts only, never overwrite. Missing assets, conflicting identities, duplicate drafts or exhausted pagination: fail before builds. The final creation-time protection remains intact to reject races. Draft discovery also handles GitHub's `untagged-*` names and paginated release lists.

Tests cover read-only exact SHA discovery, untagged Draft deduplication, forced artifacts-only builds, new revisions, missing assets, SHA mismatch, incomplete drafts, duplicate Drafts, pagination and workflow gating.
